# 溫暖馬卡龍 2D 擺鐘疊疊樂手機遊戲 (Macaron Sweet Tower)

一款專為手機觸控體驗打造的溫暖清新馬卡龍甜點風 2D 擺鐘疊疊樂遊戲。玩家控制頂部來回擺動的鐘擺懸掛物，算準時機點擊釋放，垂直下墜並以果凍擠壓彈性堆疊。未對齊部分將即時切片下墜，精準堆疊達成 Perfect 連擊可充能並施放三種強力甜點道具。

### User Review & Critical Decisions

> [!IMPORTANT]
> 依據您在互動問答中確認的偏好，本專案將鎖定以下核心規格：
> - **視覺風格**：溫暖清新馬卡龍甜點風（奶油杏白底色搭配柔和草莓粉、薄荷綠、香草黃、藍莓紫層次漸變）。
> - **道具效果**：完美對齊累積解鎖「方塊加寬 (Cake Extender)」、「時間減速 (Slow Motion)」、「甜心護盾 (Sweet Shield)」。
> - **下墜手感**：垂直直線下落，著地伴隨果凍彈性回彈（Squash & Stretch）與多餘邊緣物理切片拋落。

- **已確認決策 1**：採用 HTML5 Canvas 獨立隔離渲染迴圈搭配 React HUD 介面，達成穩定 60FPS 物理模擬。
- **已確認決策 2**：Web Audio API 程序化合成音效（無外部依賴、低延遲），支援連擊升調、切片音效、著地 Q 彈音與靜音切換。
- **推薦實作機制**：遊戲支援響應式手機模擬框與全螢幕觸控（在行動裝置直接全螢幕自適應，在桌面端提供精美手機外觀框與快捷鍵）。

### 1. 遊戲核心概念與玩法流程 (Overview & Core Gameplay)

- **核心玩法**：
  1. 螢幕頂部有平滑擺動的擺鐘（使用諧波振盪物理公式 $\theta = \theta_{\max} \cdot \sin(\omega t)$），下方懸掛著目前待掉落的馬卡龍甜點方塊。
  2. 玩家在螢幕任意位置點擊或按下空白鍵，方塊自擺鐘底部垂直直落下墜。
  3. 方塊著地並與下方的塔頂方塊做 AABB 區間重疊比對：
     - **完美對齊 (Perfect, 偏差 < 4px)**：自動微調補齊滿版，獲得「PERFECT!」特效、連擊計數器累加、加分倍率提升，並充能道具能量條！
     - **部分重疊**：超出下層邊緣的部分被瞬間切除，生成帶有重力與角旋轉的切片碎塊向下墜落；剩餘部分成為新塔頂，方塊變窄，難度逐漸提升。
     - **完全未重疊 (Miss)**：
       - 若「甜心護盾」生效中：觸發護盾破裂防禦特效，保留方塊並給予保底重試機會。
       - 若無護盾：方塊墜入深淵，遊戲結束進入結算。
  4. 隨著塔層增高，遊戲鏡頭自動平滑向上攀升（Smooth Camera Tracking），背景微變色，營造不斷登頂的甜美成就感。

### 2. 使用者體驗與視覺設計 (UX & Visual Design)

- **視覺風格與調色盤 (Macaron Pastel Sweets)**：
  - **背景畫布**：柔和溫暖奶油白至淺粉杏漸層 (`#FFF9F5` $\to$ `#FFF0E5`)。
  - **馬卡龍方塊色階**：每層依色彩光譜循環漸變（櫻花粉 `#FFB7B2`、抹茶綠 `#B5EAD7`、香草乳白 `#FFF3B0`、藍莓粉紫 `#E2B6CF`、海鹽奶藍 `#C7CEEA`、蜜桃珊瑚 `#FFDAC1`）。
  - **甜點細節**：方塊帶有圓角、細緻奶油內餡夾層高光、以及邊緣落下的糖霜碎屑粒子。
- **豐富反饋系統 (Juicy Feedback System)**：
  - **著地果凍彈性 (Squash & Stretch)**：方塊接觸瞬間 $Y$ 軸壓縮至 0.8 倍、$X$ 軸橫向擴展至 1.15 倍，隨後以阻尼彈性震盪復原。
  - **震屏反饋 (Screen Shake)**：切片下落或重大事件時，鏡頭施加微幅衰減震盪。
  - **粒子爆破 (Particle Systems)**：
    - 切除時掉落糖粒碎塊與奶油火花。
    - 完美對齊時爆發馬卡龍彩帶星塵與浮空金字「PERFECT! +Combo」。
  - **聲音反饋 (Web Audio API)**：
    - 著地「啵（Poop）」彈性音。
    - 完美連續對齊時呈現大調音階琶音逐級升高（Do-Re-Mi-Fa-Sol-La-Si-High Do），極具爽快感。
    - 切除多餘部分的俐落「喀嚓」切片音。
    - 護盾破裂音與道具釋放清脆風鈴音。

### 3. 道具系統與介面控制 (Power-Ups & Controls)

- **三種完美累積道具**：
  1. **方塊加寬 (Cake Extender)**：立即將目前塔頂方塊兩側加寬 25%，回復容錯寬度。
  2. **慢動作減速 (Slow Motion)**：使擺鐘擺動頻率降低 50%，持續 8 秒或下 3 次掉落，極佳利於抓取完美時機。
  3. **甜心護盾 (Sweet Shield)**：在塔頂周圍形成果凍透明保護膜，可完全抵擋一次落空失誤。
- **道具獲得方式**：
  - 玩家每累積 2 次連擊 Perfect 或每堆疊 8 層，即可隨機或輪替獲得一項道具（最多儲存 3 個槽位）。
  - 亦可直接點擊畫面側邊的道具欄圖示隨時觸發。
- **HUD 與暫停介面**：
  - **頂部 HUD**：當前得分、最高紀錄、當前連擊數（Combo）、音效開關切換鈕、右上角暫停鍵。
  - **暫停彈窗**：點擊暫停鍵或按 `Esc`/`P` 觸發，凍結物理迴圈，顯示「繼續遊戲」、「重新開始」、「音效設定」。
  - **結算彈窗**：顯示最終層數、獲得評級（S/A/B/C）、最高連擊與「再來一局」立即重置按鈕。

### 5. 實作驗證計畫 (Verification Plan)

1. **基本遊戲迴圈驗證**：
   - 擺鐘平滑擺動 $\theta = A \sin(\omega t)$。
   - 點擊後方塊垂直掉落並精準對位。
2. **切片與物理驗證**：
   - 偏差範圍內正確分割為「堆疊保留塊」與「切除下墜塊」，掉落塊具備重力下落與角自旋。
   - 完美對齊容差檢測（偏差小於特定像素視為 Perfect，寬度不縮減且連擊 +1）。
3. **豐富反饋驗證**：
   - 果凍 Squash & Stretch 彈動曲線。
   - 碎屑與星星粒子擴散動畫。
   - Web Audio 程序化合成音效在點擊、切片、Perfect 與 GameOver 時正常發聲。
4. **道具功能驗證**：
   - 擴展方塊寬度功能運作正常。
   - 擺鐘減速計時與恢復正常。
   - 甜心護盾觸發失誤時保底挽回並破裂。
5. **UI 與控制驗證**：
   - 暫停選單隨時可凍結與恢復畫面。
   - 重新開始一鍵重置無殘留計時器。
   - 觸控支援與鍵盤支援（空格釋放、P/Esc 暫停）。
